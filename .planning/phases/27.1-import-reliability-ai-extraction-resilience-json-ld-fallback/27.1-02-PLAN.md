<objective>
Give a page that ships valid schema.org Recipe a way to import when the AI provider fails, without
demoting AI from primary and without producing a second-class recipe.

Purpose: a working JSON-LD extractor already exists in the tree and is unreachable — today a provider
blip on a fully structured page is a hard failure. Output: an explicit, ordered fallback that mints a
real `cook_source` through the sanctioned minter, plus the log markers 27.1-05's gate depends on.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| remote recipe page → `tryExtractRecipeFromJsonLd` | Attacker-authored JSON-LD enters the recipe DTO with NO model in between. |
| seeded `StructuredRecipe` → WASM Cooklang parser | Untrusted text reaches a native parser. |
| fallback recipe → `createRecipeWithRefs` | Untrusted DTO reaches the write path. |
