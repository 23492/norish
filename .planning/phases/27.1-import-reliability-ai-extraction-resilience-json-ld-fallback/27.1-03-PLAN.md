<objective>
Make an import failure impossible to miss and impossible to swallow: guarantee the `failed` event
fires, and turn it into a rendered, dismissible error card where the skeleton was.

Purpose: today a throw in the worker's pre-emit cleanup silently kills the only signal a failure ever
produces, and even when the signal arrives it is a toast that auto-dismisses. Both add up to the
user's experience of "nothing happened".
Output: an unconditional emit with a fail-closed scope, an isolation suite covering the LIVE policy,
and a real error state in the dashboard grid.
</objective>
